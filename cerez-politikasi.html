Çerez Politikası

1. Çerezler Nedir?

Çerezler, web sitesini ziyaret ettiğinizde tarayıcınıza kaydedilen küçük metin dosyalarıdır. Bu dosyalar, web sitesinin işlevselliğini iyileştirmek ve kullanıcı deneyimini geliştirmek için kullanılır.

2. Kullandığımız Çerezler

ILGIN GROUP web sitesi aşağıdaki türde çerezleri kullanabilir:

  • • Gerekli Çerezler: Web sitesinin temel işlevselliği için gerekli
  • • Performans Çerezleri: Ziyaretçi davranışını analiz etmek için
  • • İşlevsel Çerezler: Kullanıcı tercihlerini hatırlamak için
  • • Pazarlama Çerezleri: Hedefli reklamlar göstermek için

3. Çerezleri Kontrol Etme

Tarayıcı ayarlarınızdan çerezleri kontrol edebilirsiniz:

  • • Çerezleri kabul etme veya reddetme
  • • Mevcut çerezleri silme
  • • Çerez ayarlarını özelleştirme

4. Üçüncü Taraf Çerezleri

Web sitemiz, Google Analytics gibi üçüncü taraf hizmetleri kullanabilir. Bu hizmetler kendi çerezlerini kullanabilir.

5. Çerezlerin Silinmesi

Çerezleri tarayıcınızdan silebilirsiniz. Ancak, bazı web sitesi özellikleri çalışmayabilir.

6. Daha Fazla Bilgi

Çerezler hakkında daha fazla bilgi için www.allaboutcookies.org ziyaret edebilirsiniz.
